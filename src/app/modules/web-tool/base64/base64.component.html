Base64 Specifications & Technical Reference

Standard (RFC 4648)

Uses 64 characters: A-Z, a-z, 0-9, plus + and /, with = padding at the end. Standard for data URLs and MIME attachments.

URL & Filename Safe (RFC 4648 §5)

Replaces + with - and / with _, and removes trailing = padding so strings can be safely placed in URLs, JWT tokens, and filenames without percent-encoding.

Size Overhead (+33.3%)

Base64 maps every 3 raw binary bytes (24 bits) into 4 ASCII characters (6 bits each). The encoded output is mathematically guaranteed to be ~33.3% larger than the raw binary input.
